# Create: Fuel Blast

Аддон к **Create Aeronautics** для Minecraft **1.20.1 (Forge)**.

Баки и сосуды с горючим топливом больше не безобидны: если рядом что-то взрывается —
ТНТ, крипер, бомба из аддона или выстрел из оружия другого мода — бак детонирует сам.
Чем больше топлива внутри, тем мощнее взрыв. Соседние баки подхватывают цепную реакцию.

## Что поддерживается

* Любой блок с Forge-капабилити `IFluidHandler` — то есть:
  * Fluid Tank из Create,
  * **сосуды (vessels) из Create: Connected**,
  * топливные баки Create Aeronautics,
  * баки и цистерны любых других модов.
* Топливо из аддонов:
  * **Create: Diesel Generators** — дизель, биодизель, растительное масло, этанол, бензин, нефть,
  * **Create: The Factory Must Grow** — дизель, бензин, нафта, керосин, мазут, сырая нефть, смазка,
  * любой флюид с тегами `forge:diesel`, `forge:gasoline`, `forge:kerosene`, `forge:fuel` и т.п.,
  * эвристика по названию флюида (`diesel`, `gasoline`, `jet_fuel`, `naphtha`, …) — можно отключить в конфиге.
* Мультиблоки обрабатываются как единая ёмкость: 9-этажный бак взрывается один раз, но на всё содержимое.

## Как это работает

1. Любой взрыв (`ExplosionEvent.Detonate`) сканирует область вокруг себя —
   радиус растёт вместе с мощностью исходного взрыва.
2. Каждый найденный бак с горючим «поджигается»: короткий фитиль 2–9 тиков
   и шипящий звук — именно это превращает цепочку баков в каскад, а не в одну вспышку.
3. Мощность рассчитывается по формуле
   `power = base + coefficient * (вёдра * энергия топлива) ^ exponent`, с жёстким потолком,
   чтобы промышленная цистерна не снесла сервер. Топливо при этом расходуется.
4. Взрыв разрушает блоки и поджигает округу (настраивается), а всем клиентам в радиусе
   192 блоков уходит пакет с эффектом.

## Визуал

Эффект собран слоями, как настоящий fuel-air взрыв:

| Слой | Что делает |
| --- | --- |
| Вспышка + ударный фронт | `FLASH` и кастомная частица `shockwave` — диск, который резко расходится и гаснет |
| Приземный огненный «бублик» | кольцо фаерболов и дыма, стелющееся по земле |
| Ядро | облако `fireball`-частиц, разлетающееся во все стороны |
| Гриб | поднимающаяся колонна, остывающая по цвету |
| Осколки | угли (`ember`) с гравитацией, отскоками и мерцанием + капли лавы |
| Туман топлива | `DustParticleOptions`, окрашенный в реальный цвет флюида |
| Дым | долгий `LARGE_SMOKE`, остающийся после огня |

Частицы физически правдоподобно остывают: белый → жёлтый → оранжевый → тёмно-красный → чёрный дым,
растут по ease-out кривой, всплывают за счёт подъёмной силы и светятся собственным светом.
Звук — многослойный: взрыв, шипение огненного заряда и низкий гул для больших детонаций.

## Конфиг

`config/fuelblast-common.toml`:

| Опция | По умолчанию | Описание |
| --- | --- | --- |
| `scanRadius` | 6.0 | базовый радиус поиска баков |
| `radiusPerPower` | 0.75 | прибавка радиуса за единицу мощности исходного взрыва |
| `minFuelMb` | 250 | минимум топлива для детонации |
| `basePower` / `powerCoefficient` / `powerExponent` | 1.5 / 1.35 / 0.62 | кривая мощности |
| `maxPower` | 14.0 | потолок мощности |
| `minFuseTicks` / `maxFuseTicks` | 2 / 9 | фитиль |
| `breakBlocks`, `causeFire` | true | разрушение и поджог |
| `maxChainDepth` | 6 | глубина цепной реакции |
| `fuelValues`, `fuelTags`, `blacklist` | см. файл | список топлива и его энергия (1.0 = дизель) |

Неизвестные id в списке просто игнорируются, так что конфиг безопасен без установленных аддонов.

## Сборка

```bash
gradle wrapper        # gradle-wrapper.jar не хранится в репозитории
./gradlew build       # готовый jar в build/libs
./gradlew runClient   # запуск дев-клиента
```

Зависимости для dev-окружения (Create, Registrate, Flywheel) тянутся из maven.tterrag.com.
Опциональные аддоны для тестов раскомментируйте в `build.gradle`.
